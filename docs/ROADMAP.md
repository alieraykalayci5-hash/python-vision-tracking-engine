# Roadmap (planned — no promised dates)

- **Validation:** reproduce actual YOLO inference on Windows and Linux, publish detector/integration smoke results.
- **Packaging:** improve installation, compatibility, GPU setup instructions and release artifacts.
- **Tracking quality:** test on labeled public MOT benchmark sequences and publish IDF1/HOTA and reproducible configuration.
- **Performance:** compare optional C++ and SciPy assignment on equal problem sizes; only claim speedups with evidence.
- **OSS maintenance:** triage real issues, respond to useful PRs, cut semantic version tags with changelog and upgrade notes.
- **Long-term:** explore bbox-aware matching, better occlusion handling and evaluation workflows.
