# Security policy

This repository is an early-stage research/development tool and has no published supported-version or security response SLA.

If GitHub private vulnerability reporting is enabled, use it for sensitive disclosures. Otherwise contact the maintainer privately through contact information publicly provided in the GitHub profile. Do not put exploit details, credentials, or private footage into public issues.

Include relevant versions, reproduction steps, impact, and proposed mitigation. Validate third-party weights and input files before using them.
